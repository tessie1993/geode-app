# Geode's sound engine

Geode's visuals are only as good as what they hear. Two separate paths carry sound and they must not be confused:

1. **Playback chain** (Kotlin, Media3): ExoPlayer runs `MvzAudioProcessorChain` on its playback thread. `PcmTap` is first, before any DSP, so DSP never moves the visuals. Read `docs/AUDIO_CHAIN.md` in full before touching it. Two rules never bend: the tap stays first, and the chain never gets float output.
2. **Sound engine** (C++, `core/sound`): every renderer owns one. On each GL frame it is fed its ring's new PCM natively (`AudioBus.soundSource`, `core/viz/SoundFeed`) and stepped with that frame's dt into a `GeodeSoundFrame` (`core/sound/SoundFrame.h`). Styles read it through `lib_sound`.

## Where things are

| Need | Open |
|---|---|
| Spectrum, bands, FFT | `core/sound/Fft.*`, `FilterBank.hpp`, `Stages.hpp` |
| Tempo, beat, bar, phrase (fixed 10 ms hop of written samples, not frames) | `core/sound/Rhythm.*` |
| Chroma, key, chord, tension, scale | `core/sound/Harmony.*`, `ScaleTable.inc` (generated by `tools/musical_intelligence.py` from `docs/musical-intelligence/`) |
| Novelty, sections, build-up, drop | `core/sound/Form.*` |
| Valence, energy, tension, GEMS-9 | `core/sound/Emotion.*`, `EmotionTable.inc` (generated by `tools/music_emotion.py`) |
| Rest-when-silent (wallpaper, dream, edge glow, capture screen) | `core/sound/Silence.hpp`, applied per ring as `geode_ingest_resting`; the UI level is `core/audio/ingest/Level.hpp` |
| Export resampler and BS.1770 meter | `core/audio/dsp/PcmResampler.*`, `Loudness.*` |
| Design history and open questions | `docs/research/sound-engine-v2.md`, `docs/research/note-key-response.md` |

## Rules

- Engine logic lives in C++ (ADR 0003). Kotlin only feeds samples and reads results.
- Export must equal live: `OffscreenSceneRenderer` steps its own engine at 1/fps from `TrackAudio`. Anything that depends on wall-clock time or frame rate breaks that.
- Never edit `ScaleTable.inc` or `EmotionTable.inc` by hand: change the CSV or the generator and regenerate.
- A new `GeodeSoundFrame` value is also a new `ReactSource`. Update the reaction DNA (`core/viz/ReactionDna`) and the wire layouts the JVM tests check (`engine/scenes/src/test/`).

## Prove it on the host (no device, no Gradle)

```sh
g++ -std=c++20 -O1 -Wall -Wextra -Icore core/tests/sound_test.cpp core/sound/*.cpp -o /tmp/sound_test && /tmp/sound_test
g++ -std=c++20 -O1 -Wall -Wextra -Icore core/tests/musical_test.cpp core/sound/*.cpp -o /tmp/musical_test && /tmp/musical_test
```

`.github/workflows/android.yml` has the exact line for every other native test (director, note response, resampler, loudness). Write the test first: the engine is pure C++, so every detector can be driven with synthetic PCM (clicks for beats, sines for chroma, silence for `Silence`).
