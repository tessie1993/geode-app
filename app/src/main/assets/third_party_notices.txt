psrdnoise
---------
app/src/main/assets/shaders/lib_psrdnoise2.glsl is vendored verbatim, with its licence
header intact, from:

  https://github.com/stegu/psrdnoise

  "Authors: Stefan Gustavson (stefan.gustavson@gmail.com) and Ian McEwan
   (ijm567@gmail.com). Version 2021-12-02, published under the MIT license.
   Copyright (c) 2021 Stefan Gustavson and Ian McEwan."

The full MIT text is in the file itself. It backs the curl-noise velocity field
(app/src/main/assets/shaders/curl_field_frag.glsl): psrdnoise returns an ANALYTIC gradient, which is
what makes that field exactly divergence-free rather than approximately so - the
field previously took central differences, and the error in a finite difference
IS the divergence that makes particles pile up. It also cut the field from
twelve noise evaluations per pixel to three, and its periodic mode is what a
seamless loop would be built on.

Scientific colour maps (cyclic)
-------------------------------
app/src/main/assets/shaders/cyclic_palettes.bin packs the five CYCLIC scientific
colour maps - bamO, brocO, corkO, romaO, vikO - at 256 entries each, RGB8,
3840 bytes for the set. Source distribution:

  https://github.com/callumrollo/cmcrameri  (cmcrameri/cmaps/*.txt)

whose LICENSE.txt states, in full attribution of the data as distinct from the
packaging:

  MIT License
  Colormaps in cmcrameri/cm/cmaps: Copyright (c) 2020 Fabio Crameri
  Python scripts and packaging: Copyright (c) 2020 Callum Rollo

Only the colour-map data is used; none of the Python is. The originals are
Fabio Crameri's Scientific colour maps (https://www.fabiocrameri.ch/colourmaps/),
whose citation is requested as a courtesy: Crameri, F. (2018), Scientific
colour maps, Zenodo, doi:10.5281/zenodo.1243862.

These are the CYCLIC members of the family specifically: their two ends join.
Measured on the packed atlas, the wrap gap is 0-2/255 against a largest
ordinary step of 3/255 - the seam is smaller than the distance between
neighbouring entries, which is what makes them safe for a circular quantity
where a hue ramp would band on lightness instead.

Style families: techniques studied (no code used)
--------------------------------------------------
The Arbor, Bulb, Chrysanthemum and Lucid style families
(app/src/main/assets/shaders/lib_arbor.glsl, lib_bulb.glsl, lib_chrys.glsl,
lib_lucid.glsl and their arbor_*, bulb_*, chrys_*, lucid_* styles) are original
code. The following Shadertoy works are licensed for non-commercial use only
(CC BY-NC-SA 3.0, stated or the Shadertoy default), so none of their code is
used; they are credited here as the pieces whose techniques were studied:

  "fractal trees gif" by macbooktall   https://www.shadertoy.com/view/llXfRr
    (folded IFS branching distance field)
  "mandelbulb_" by EvilRyu             https://www.shadertoy.com/view/MdXSWn
    (power-8 Mandelbulb distance estimate, after White and Nylander, 2009)
  "Breakthrough Chrysanthemum" by OneHung
                                       https://www.shadertoy.com/view/s3ySzz
    (polar petal fields, blooms that hide a scene change)
  "dmt, no! not the drug" by Arrangemonk
                                       https://www.shadertoy.com/view/sdyXWW
    (recursive domain warping, after Inigo Quilez's articles on the technique)


The Glass style family (app/src/main/assets/shaders/lib_glass.glsl and its
glass_* styles) is original code written from the published technique:

  Christophe Schlick, "An Inexpensive BRDF Model for Physically-based
  Rendering", Computer Graphics Forum 13(3), 1994
    (the Fresnel approximation behind the family's reflections)


The Nebula style family (app/src/main/assets/shaders/lib_nebula.glsl and its
nebula_* styles) is original code written from the published technique; no
Shadertoy code is used. Credited as the best-known demonstration of it:

  "Star Nest" by Kali                  https://www.shadertoy.com/view/XlfGRj
    (volumetric fly-through star field and gas)


The Terrain style family (app/src/main/assets/shaders/lib_terra.glsl and its
terra_* styles) is original code written from the published technique; no
Shadertoy code is used. Credited as the best-known demonstration of it:

  "Elevated" by iq (RGBA, Breakpoint 2009)
                                       https://www.shadertoy.com/view/MdX3Rr
    (ray-marched fbm heightfield terrain with fog and sky)


The Truchet style family (app/src/main/assets/shaders/lib_truchet.glsl and its
truchet_* styles) is original code written from the published technique:

  Sebastien Truchet, "Memoire sur les combinaisons" (1704), and Cyril Stanley
  Smith, "The Tiling Patterns of Sebastien Truchet and the Topology of
  Structural Hierarchy", Leonardo 20(4), 1987
    (randomly oriented tiles whose arcs join into continuous paths)


The Sphere Foam style family (app/src/main/assets/shaders/lib_foam.glsl and its
foam_* styles) is original code written from the published technique; no
Shadertoy code is used. Credited as the best-known demonstration of it:

  "Apollonian" by iq                   https://www.shadertoy.com/view/4ds3zn
    (sphere inversion and domain repetition into an Apollonian packing)


The Flame, Opal and Hollow style families (app/src/main/assets/shaders/
lib_flame.glsl, lib_opal.glsl, lib_hollow.glsl and their flame_*, opal_* and
hollow_* styles) are original code; no third-party shader code is used.


The Prism, Fluor, Loom, Shard, Petal and Fold style families (app/src/main/
assets/shaders/lib_prism*, lib_fluor*, lib_loom*, lib_shard*, lib_petal* and
lib_fold* and their prism_*, fluor_*, loom_*, shard_*, petal_* and fold_*
styles; prism_rain is not one of them) are original code; no third-party
shader code is used.
