# Style thumbnails

Pre-baked picker thumbnails, one `<styleId>.webp` per style id in the native catalogue (256x256 lossy WebP, quality 75, about 10 KB each, so roughly 2.4 MB of APK for all ~237 styles). They are not drawn by hand: the manual workflow `.github/workflows/render-thumbs.yml` runs the instrumented test `dev.geode.thumbs.StyleThumbnailRenderTest` on the CI emulator, which renders every style offscreen at 512x512 through the real native renderer while a fixed synthetic groove drives its sound engine, keeps the frame after a few seconds of warm-up, and opens a `bot/style-thumbs-<run>` PR with the results; rerun it (optionally for a few ids) when a style's look changes. MilkDrop has no file here, and any style whose file is missing (a new style not yet rendered, or one that failed to render) falls back to the picker's generated art, so a missing thumbnail is never an error.
