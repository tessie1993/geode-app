# The native host tests: one entry per test, read by tools/host-tests.sh (CI: native-host-tests.yml; by hand: bash tools/host-tests.sh).
# Each test's sources are named here and nowhere else, so moving a C++ file edits this file and no workflow.
#
#   name | profile | sources | run
#
#   name     the binary: the compiler's -o, built in the repository root.
#   profile  a `profile` line below: the flags the test is built with.
#   sources  every file the binary is built from, in link order; $VARS and globs expand as in a shell.
#            `@NAME` is test NAME's sources, so a test built again under another profile names no file twice.
#   run      the arguments the binary is run with (empty: none; `-`: built, not run).
#            An optional fifth field is an environment prefix for the run (NAME="value").
#
# `@group NAME` puts the entries after it in that group; tools/host-tests.sh runs one group (default: main),
# and the workflow runs a group per step. `@pre basisu` builds Basis Universal's objects before the next entry.
# A line ending in a backslash goes on. A new test: add its entry here (nothing in the workflow), then
# `bash tools/host-tests.sh --only NAME` builds and runs it alone; `--dry-run` prints every command instead.

# overrun, a leak or undefined behaviour stops the test, where an ordinary build may read stale memory and pass.
