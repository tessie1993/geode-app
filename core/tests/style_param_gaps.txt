# Why each field is here (each needs an owner decision, not an invented effect):
#   motionDrift  Spin drift turns only a style the catalogue gives a spin rate (catalogue::spinRate, the
#                owner's rule that bars, grids, landscapes and trees hold still); MotionField adds nothing
#                to the others. Fix: hide it there (a scope), or give the style a spin rate.
#   note*        Note & key reactions drive only the six style knobs (uKnob), and these styles name none:
#                the marched families and the dedicated renderers. Fix: each style spends the knobs on its
#                own look, as lib_neon does, or the Notes & key block hides where no knob is read.
#   midGain      These shader styles hear no mid band field (SND_MID*, the mid presence or flux, uMidRel)
#                and do not spin, so Mid gain reaches them only through a reaction route that picks a mid
#                source. Fix: hide it there (a per-style band scope, as Detail is per style), or hear mids.
