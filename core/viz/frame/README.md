# core/viz/frame

Part of the target in [ADR 0006](../../../docs/adr/0006-fosfora-aligned-engine.md). [ADR 0008](../../../docs/adr/0008-frame-pacing-heat-and-rest.md) sets the pacing, heat and rest rules.

**Here now:** `Pass.hpp` (the interface below, with `Surface`, `FrameCtx`, `PassInputs`, `PassTarget`) and its first pass, `EdgeGlowPass` (the wallpaper's edge look, once Kotlin GL; pure maths in `EdgeGlowMath.hpp`, pinned by `core/tests/edge_glow_test.cpp`, #439); `Renderer` still calls it directly, after the composite, and there is no `FrameGraph` yet. And `FixedRateClock` (Cast's frame clock: steady slots, a stall drops frames instead of bursting, monotonic PTS, the audio cut; reached through `geode_frame_clock_*`, tested by `core/tests/cast_clock_test.cpp`) and `Pacer.hpp`, the frame clock every surface shares. It decides which vsyncs a surface draws on (a whole-number divide of the measured panel rate) and owns the one dt clamp, `clampDt`, which `Renderer::beginFrame` uses too. Android keeps the Choreographer callback (`render/FramePacer.kt`). It is reached through `geode_pacer_*` and tested by `core/tests/pacer_test.cpp`. It paces to the effective cap, the surface's cap under the thermal step (`ThermalState::capFor`), and records it in the state so `FramePacer` re-asks `Surface.setFrameRate` when the thermal cap moves.

**Here now:** `Thermal.hpp`, the process's one thermal state (`ThermalState::process()`, #440). It holds PowerManager's readings, the once-a-second cadence (`claimSample`), the NaN rule (a missed window keeps the last real headroom for 10 s), the dwell and the settled tier; every `Renderer`'s `ThermalGovernor` (`core/viz/ThermalGovernor`) reads it and adds only what that renderer alone sees (its frame times, an export's pin to Full). The tier ladder `thermalTierInfo` is the owner's fps-first order: fps a rung down per tier (a 60 cap to 30; a live 90 or 120 walks 120, 90, 60, 30, `thermalStepCapFps` in `LiveFps.hpp`), then render scale, then march scale, then post FX. Android keeps only the reads (`render/ThermalGovernor.kt`). It is reached through `geode_thermal_*` and tested by `core/tests/thermal_test.cpp`.

**Here now:** `LiveFps.hpp`, Settings › Performance's live cap above 60 (owner, 2026-11-12): the caps a display is offered (30 and 60 always, 90 and 120 where a seamless refresh rate shows them evenly), the stored cap snapped to the display it is applied on, and the thermal walk down the rungs; and Follow device (`kLiveFpsFollow`, -1 in `perf_fps_cap`): the stage states no rate (`setFrameRate(0)`), draws every vsync of the panel the system chose (the pacer's own estimate; its paced slot reads that rate), and when hot steps down from the rate it last followed while cool (`followCapFps`, kept in the pacer state's ninth slot), so a panel the system lowers under a hot phone cannot walk it to the floor. The stage only; the wallpaper, the dream, an export and Cast keep their own rates. Reached through `geode_live_fps_*`, tested by `core/tests/live_fps_test.cpp`.

**Beside it, still in `core/viz`:** `SurfaceRun.hpp`, the wallpaper's and the dream's run rule (stopped, still, moving; reduced motion holds a still frame), the still frame's settle and each surface's fps choice, which caps its pacer. Reached through `geode_surface_*`, tested by `core/tests/surface_run_test.cpp`.
**Here now:** `Cadence.hpp`, what a live surface's frame owes the shell (#604). `VisualizerRenderer.kt` makes one call per frame, `geode_viz_frame_begin`, with the pacer's cap and Settings › Performance; native applies the quality only when it changed (`offerQuality`, equal by bits so a NaN pref is applied once), clears a new surface's first frame and builds nothing on it (`Renderer::clearToBlack`, so the main thread `GLSurfaceView` parks in `surfaceChanged` is released at once), and answers a bitmask: `GEODE_FRAME_THERMAL_DUE` when this surface won the process's thermal slot, `GEODE_FRAME_LIQUID_CHANGED` with the new Liquid mode. Android keeps only the PowerManager read the bit asks for. Tested by `core/tests/renderer_cadence_test.cpp`.

Export post-passes: `ExportPasses` (watermark and loop seam; #442) with their pure maths in `ExportPassMath.hpp` (`core/tests/export_passes_test.cpp`) and the loop seam's driver and GPU budget in `LoopSeam.hpp` (`core/tests/loop_seam_test.cpp`, #603), driven through `geode_export_*` until `FrameGraph::run` owns the export frame.

**Here now:** `PushVersions.hpp`, which of the shell's pushed inputs a live frame still owes native (#751). The shell keeps a version per input (scene params, LFO configs, ADSR configs, sound tuning; one counter that every write raises, `VisualizerRenderer.kt` and `PushedConfigs`) and hands the four to `geode_viz_frame_begin`; native answers `GEODE_FRAME_PUSH_*` for each version it has not applied (an equal or older one is skipped, so a stale write cannot undo a newer push; a new surface wants all four again), and the shell packs and pushes exactly those. Reaction routes are not here yet. Tested by `core/tests/push_versions_test.cpp`.
**Here now:** `HlsSegments.hpp`, Cast's HLS segment durations from the fragments' media time and the playlist text (#656; `core/tests/hls_segments_test.cpp`). `LinkShare` and `LinkPage.hpp`, "Show on a computer": the stream's routes under the token, every response head, the browser's page and its master playlist (codecs from the init segment), and the share's state (`geode_link_*`; `core/tests/link_share_test.cpp`; its QR code is `core/util/QrCode`, `core/tests/qr_code_test.cpp`). `CastTee`, the stage's own frames into the cast stream through shared GPU buffers, no second render (`geode_cast_tee_*`, `geode_viz_set_cast_source`; its rules in `CastTeeRule.hpp`, `core/tests/cast_tee_test.cpp`).

**Owns:** the one frame function every surface runs (screen, PiP, second screen, wallpaper, dream, Studio preview, export, thumbnails), and the pieces it is built from.
- Cast's frame timing, as the one surface that streams its frames: the fixed-rate frame clock that stamps each frame's PTS, and the HLS timing of the stream those frames become (each segment's media duration read from its fragment, the stream's fixed `EXT-X-TARGETDURATION`, the playlist text), and what the stream's server answers (`LinkShare`). Sockets and byte cutting stay in Kotlin's `cast/`.
- `FrameCtx`: this frame's effective params (from `core/signal`), the sound frame and source snapshot, camera pose, touch, flow, palette LUT, knobs. Replaces the ~20 `Scene` setters (`setPaletteLut`, `setTouchField`, `setCamera`, …; `core/viz/Scene.hpp:22-62`) and the `SceneHost` callbacks (`:65-76`).
- `Pass`: `prepare(FrameCtx)`, `draw(inputs, target)`. Trail, Liquid, Composite, UiBlur, and the post-passes (watermark and loop seam, still Kotlin GL; edge glow, native since #439) all implement it.
- `LayerStack`: entries of scene + params + blend + mix. Replaces the three ad-hoc slots (layer, outgoing, born; `Renderer.hpp:333-336`, `:314-318`).
- `FrameGraph::run(FrameCtx)`: a fixed, readable pass list. `Renderer` keeps the scene cache, `ScenePrep`/`ProgramStager` and the targets, and calls it.

**Moves out of `Renderer` (as of `cf7e88f`):** the sound engine (to `core/sound`), the modulation chain (to `core/signal`), Liquid's state and born scenes (`stepLiquid`, `drawLiquid`, `RendererFrame.cpp`) into a `LiquidStage` pass, quality decisions folded into params (`p.rippleOverlayEnabled = false`) into pass toggles.

**Keep as they are:** `ScenePrep`, `ProgramStager`, `ProgramBinaryCache`, `GlCaps`/`GlProber`, `VisualSafety` (as the last step before drawing), the catalogue text table.

**Shader contract** (shaders stay in `app/src/main/assets/shaders`): a generated params uniform block from `core/signal/params` and a generated sound block from `core/sound/schema`, pasted by the prelude every style includes; include-once in `core/viz/ShaderSource.cpp`, exposed through the C ABI so `tools/check_shaders.py` stops re-implementing the resolver (the Kotlin `GlUtil` copy is gone, #603). Family libraries (`lib_<family>`, `lib_neon`, `lib_relief`, `lib_camera`) stay, on top of the prelude.

**fosfora:** `gpu/frame_prep.rs`, `gpu/frame_graph.rs` (`execute_and_composite`, "extracted … the headless scene renderer would have been a third copy"), `gpu/layer.rs` (`Layer`, `LayerStack`), `gpu/uniforms.rs` (append-only, layout-guarded).

**Here now:** `FixedRateClock.hpp`, the fixed-rate frame clock Cast paces by (#572; `core/tests/cast_clock_test.cpp`), and `HlsSegments.hpp`, Cast's HLS segment durations from the fragments' media time and the playlist text (#656; `core/tests/hls_segments_test.cpp`).

**Test that proves it:** the thumbnail render test (`StyleThumbnailRenderTest`) and an export of a fixed project produce the same frames before and after each move (pixel diff within tolerance).
