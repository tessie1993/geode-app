# Repository audit, September 2026: bugs, incomplete features, fix plan

## Context

The user asked for a read-only scan of `tessie1993/geode-app` (Android music player + GPU
visualizer; Kotlin/Compose in `app/` and `engine/`, C++20 core in `core/`, JNI in
`app/src/main/cpp`, shaders in `app/src/main/assets/shaders`) to list every bug and every
incomplete feature, then a plan that small Sonnet agents can execute without conflicting with
each other or the codebase's conventions, and finally to offload that plan to a fleet of Sonnet
agents.

Constraints the user set:
- No building, no unit tests, no device steps (the Android SDK/NDK is not installed here).
- Workers verify by running the read-only `code-review` skill on their diff and fixing findings.
- One draft PR per unit, each on its own branch `claude/repo-audit-fix-plan-rfw176-uNN`.
- No assumptions, no hallucination: every item below was located in the tree and quoted by
  file:line by the scan agents; items the code contradicted were dropped (listed at the end).

Three scans ran: docs/CHANGELOG/comments for self-admitted gaps; Kotlin app + engine for bugs
and unfinished wiring; native core + JNI + shaders + tools. GitHub has zero open issues. Three
open draft PRs (#4, #7, #14) sit on other branches and are left alone.

There are no literal `TODO`/`FIXME` markers outside `third_party/`; every gap lives in prose or
in code that is written but unreachable.

## Findings

### Bugs (confirmed in code)

Kotlin / engine
- `PresetStore.fromJson` defaults for `symmetry` (0), `fluidCatchPoints` (0), `fluidParticleLife`
  (12.0) disagree with `SceneParams` (6, 2, 6f) — `app/.../data/PresetStore.kt:358,442,445` vs
  `engine/scenes/.../render/scene/SceneParams.kt:35,102,106`. Old presets/links decode wrong.
- Transition style/id/duration never persisted and never call `vizStateStore.persist()` —
  `app/.../ui/VisualSettingsController.kt:84-99`; `VizStateStore` only stores live_state + milk_path.
- `sectionStaging` never persisted; `randomEnabled` not stored though its sibling
  `vizPlaylistEnabled` is — `app/.../ui/AutoVisualsController.kt:195-204,112-123`,
  `app/.../ui/AutoVisualsPrefsStore.kt`.
- `GuiPrefs.micReactive` written on every mic toggle but never saved or loaded —
  `app/.../ui/AppTheme.kt:147`, `app/.../ui/PlayerSession.kt:119-121`.
- `NativeViz.handle` is a plain var written on GL and main threads; `create()` unsynchronised —
  `engine/scenes/.../render/bridge/NativeViz.kt:22-43`; `EnginePlumbing.kt:87-93` mutates off the GL
  thread while line 77 in the same file uses `queueEvent`.
- `VisualizerRenderer.onMilkPresetLoaded` lacks `@Volatile` while its sibling has it —
  `engine/scenes/.../render/VisualizerRenderer.kt:67-70`.
- `AnalysisEngine.close()` destroys the native analyzer while the loop may still be inside
  `analyze()` — `engine/scenes/.../analysis/AnalysisEngine.kt:198-206`.
- `OfflineAnalyzer` leaks the native `StreamingPipeline` on every non-success path (the AIFF branch
  a few lines up closes it correctly) — `engine/scenes/.../analysis/OfflineAnalyzer.kt:67,134-142`.
- `NativePlayer.handleRelease()` calls `playerDestroy` while worker tasks may still run
  `playerOpen`/`playerSetNext` — `app/.../playback/NativePlayer.kt:149-157,293-332`.
- `WidgetPublisher.clear()` cancels its scope right after launching the redraw —
  `app/.../widget/WidgetPublisher.kt:70-74`.
- `PlaybackFades`: nested `fadeThen` orphans the fade-in job; loop runs `steps+1` times —
  `app/.../ui/PlaybackFades.kt:50-62,83-86`.
- Binder IO (`Settings.Secure`, `MediaSessionManager`, `PackageManager`) on Main every 500 ms —
  `app/.../ui/PlayerSession.kt:1235-1250` → `CaptureController.kt:192-196`.
- Up to 1001 synchronous `ContentResolver.query` calls on Main when opening files —
  `app/.../ui/QueueController.kt:73-79,127-135`.
- Android Auto `onGetChildren`: `page * pageSize` Int overflow → negative `subList` index —
  `app/.../playback/PlaybackService.kt:81-84`; `LibraryTree.tracks()` rescans MediaStore per node
  and twice per playlist — `LibraryTree.kt:105-116`.
- `HistoryStore` trims by recency but ranks by play count, so most-played entries vanish after
  restart — `app/.../data/HistoryStore.kt:141`.
- `ThermalGovernor.pacedFps` read every frame, written by nobody (native governor always sees 0) —
  `engine/scenes/.../render/ThermalGovernor.kt:22`, `VisualizerRenderer.kt:199`.
- `AudioTranscoder.durationUs` pads the last AAC frame with a hardcoded 24 ms —
  `app/.../export/AudioTranscoder.kt:23-26`.
- `SmartPlaylistStore` drops the whole file on an unknown enum token —
  `app/.../data/SmartPlaylistStore.kt:158`; `EditorProjectJson.kt:225` uses `origin!!`;
  `SessionStore` writes a version it never reads — `SessionStore.kt:51,64-85`.
- `AudioCapturePump.stop()` may return with the worker still writing into the sink —
  `app/.../audio/AudioCapturePump.kt:102-109`; `PlaybackCaptureService` posts its notification
  before honouring `ACTION_STOP` — `PlaybackCaptureService.kt:38-42`; `PlaybackService.ensureRunning`
  uses `startService` and swallows the background `IllegalStateException` — `PlaybackService.kt:212-216`.
- `NativePlayer.handleAddMediaItems` adjusts `currentIndex` only when something is loaded, unlike
  remove — `NativePlayer.kt:220`; `RenderEta.latestMs` written, never read — `RenderEta.kt`.
- "Loop safe" chip silently does nothing without a tempo — `app/.../ui/SettingsDialog.kt:231-234`.

Native
- Resampler: unsigned underflow / out-of-range `erase` when input rate > 4× output —
  `core/audio/player/Resampler.cpp:37,56-66`.
- `AnalysisSession::pull`: `buffered_ - hop` underflows when hop > fftSize (≥122.88 kHz sources
  with the 60 Hz offline hop) — `core/analysis/AnalysisSession.cpp:75,85-89`.
- Waveform block average divides by `fftSize/128 == 0` for small FFT sizes → NaN into shaders —
  `AnalysisSession.cpp:133-140`; `geode_api.cpp:29` only requires `fft_size >= 2`.
- Transition progress is NaN at 0 ms duration so the outgoing scene is never released; and
  `transitionDurationMs_`, `requestedParams_`, `layerMix_`, `layerBlend_`, `transitionId_`,
  `reducedMotion_` are read on the GL thread without `stateLock_` — `core/viz/RendererFrame.cpp:167,
  229-233,94-95`, `Renderer.cpp:328`.
- `deliverPcm` holds `stateLock_` across the scene callback, so the PCM producer can block —
  `RendererFrame.cpp:145-148` (contrast `feedFormDrive` at 109-119).
- `geode_player_set_dsp` can return on its 200 ms timeout with the audio thread still inside the
  old chain — `core/audio/player/Mixer.cpp:49-57`.
- Limiter rescans the whole lookahead window per sample (O(n) in the audio callback) —
  `core/audio/dsp/Limiter.cpp:29-32`; no `setSampleRate` on any DSP stage, so a route change to a
  96 kHz DAC leaves a 48 kHz-designed EQ and half-length limiter — `DspChain.hpp:14-16`,
  `Player.cpp:233-247`.
- JNI `drumsStep` never checks the `bands` array length against the handle's band count —
  `app/src/main/cpp/geode_jni.cpp:198-204`, `core/analysis/DrumChannels.cpp:22`.
- `ReactiveAnalyzer::reset()` does not clear `lastFrameSilent_` — `ReactiveAnalyzer.cpp:113-157`;
  `AnalysisSession::push` grows its buffer without bound — `AnalysisSession.cpp:58-62`.
- `Output::isOpen()` is true for a stream Oboe already closed; `Player::run` handles commands
  before the disconnect check — `Output.hpp:25`, `Output.cpp:83-86`, `Player.cpp:107-112`;
  `postCommand` can spin forever — `Player.cpp:320-329`.
- Tags: NULL and "" both overwrite a field although the header says NULL clears and the JNI never
  passes NULL, so a short array blanks the rest — `geode_tags_api.cpp:66-78`, `Tags.cpp:89-95`,
  `geode_tags_jni.cpp:70-73`; `writeTags` returns bare false for four causes — `Tags.cpp:82-103`.
- GL teardown asymmetry on surface recreation (`zeroTex_`, `quadVao_` never deleted between
  contexts) — `Renderer.cpp:214-256`, `CompositePass.cpp:22-25`; `geode_viz_last_error` returns a
  pointer into GL-thread-mutated state — `geode_viz_api.cpp:229-231`.
- Nested `//#include` inside a shader library is silently dropped — `core/viz/ShaderSource.cpp:80-85`.
- `tools/check_style_collection.py:31-38` reads six `dev/musicviz` paths that no longer exist.

### Incomplete features (written but unreachable, or self-admitted)

- Video templates: `TemplateFormat.kt`, `VideoTemplate.kt`, `TemplateRepository.kt` (~1980 lines)
  have no caller, no DI binding, no screen, no strings; `geode://template/...` host is not in the
  manifest (`AndroidManifest.xml:126-128` registers only `preset`).
- Loop render / long-form: `export/LoopRender.kt` (858 lines), `export/LoopExtend.kt` (698) have
  no caller; `GeodeContainer.RENDER_SCRATCH_PREFIXES` sweeps `geode_loop_` files nothing creates.
- EBU R128 loudness: `export/LoudnessMeter.kt`, `export/LoudnessTarget.kt` have no caller; no
  export path normalises loudness.
- Playlist file formats: `data/PlaylistFormats.kt` (M3U/PLS/XSPF parse + resolve) has no caller.
- Tag writing for MediaStore tracks the app did not create: README maintainer note says the
  library screen does not launch `MediaStore.createWriteRequest` yet; `grep createWriteRequest`
  finds nothing; `DuplicatesTab.kt:44-85` already does the sibling `createDeleteRequest` flow.
- Analysis cache (format v2) does not store the musical-structure fields (`tempoStability`,
  `barPhase`, `beatInBar`, `downbeat`, `downbeatConfidence`, `novelty`, `sectionBoundary`), so a
  timeline loaded from cache has zeros there — `CHANGELOG.md:54-56`, `AnalysisCache.kt:14,140+`.
- Kotlin `LfoEngine.tick` / `AdsrEngine.tick` have no callers; `VisualizerRenderer.syncNativeState`
  forwards only `.configs` to native — `Lfo.kt:185`, `Adsr.kt:41`, `VisualizerRenderer.kt:75-77,185-194`.
- Unused strings that describe UI nobody draws: `studio_reset`, `studio_nothing_changed`,
  `studio_renders_new_file`, `action_visualise`, `action_export_now`, `action_add_to_studio`,
  `settings_tab_help`, `settings_intent_body` — `strings.xml:50,80,287-289,381-383`;
  `AppSettingsTab.kt:24` hardcodes the tab titles instead.
- `docs/AUDIO_CHAIN.md:96-110` specifies a "DSP does not move the visuals" sentence on every
  audio-DSP screen; not present in any string or composable.
- `docs/PARAM_MATRIX.md` lacks the live `marchDetail` row, names `FxCompositor` (absent) and the
  old Kotlin scene classes, and marks 20+ family cells as direct readers where the native family
  source never reads the param (list in the docs unit).
- `ENABLE_PLAYLIST ON` packages `libprojectM-4-playlist.so` that nothing calls (README says set OFF).
- `tools/shaderpreview` is documented as stale and unable to run since the C++ port.
- Doc mismatches: `android.yml:73-74` cites a `ShaderSyntaxTest` that does not exist;
  `release.yml:44` comment contradicts line 49; `AUDIO_FEATURE_ABI.md:21` links a missing
  `ENGINE_V2_PLAN.md`; `SOURCE_ARCHIVE.md:152-156` describes a `checkThirdPartyNotices` task that
  does not exist (the check lives in `geode.provenance.gradle.kts`); `provenance.json` and
