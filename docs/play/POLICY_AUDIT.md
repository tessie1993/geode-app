### Permissions

#### The live-input microphone loop is started and stopped only by the user toggle, by playback-state changes and at session shutdown. The evidence shows no lifecycle stop when the app goes to the background.
- **Policy**: **Audio Recording Policy**
- **Severity**: 🔵 Suggestion
- **Files**: [AndroidManifest.xml](../../app/src/main/AndroidManifest.xml), [AudioCapturePump.kt](../../app/src/main/java/dev/geode/audio/AudioCapturePump.kt), [MicCapture.kt](../../app/src/main/java/dev/geode/audio/MicCapture.kt), [CaptureController.kt](../../app/src/main/java/dev/geode/ui/CaptureController.kt)
- **Evidence**: AudioCapturePump.kt:70 runs 'while (running && runGeneration == generation)' reading AudioRecord on a daemon thread until stop(). For the mic, stop() is reached only through CaptureController.setMicEnabled(false) (:126-128) and shutdown() (:250). CaptureController.start() (:95) also restores the mic automatically from a saved preference. The evidence files contain no ON_STOP or onStop pause. Two things mitigate this. RECORD_AUDIO (manifest line 17) is requested only when the user turns Live input on, and samples go only to an in-memory analysis buffer. No FOREGROUND_SERVICE_MICROPHONE or 'microphone' foregroundServiceType is declared, so on targetSdk 36 the platform gives a backgrounded app silence, and Android 12+ shows the system mic indicator. This is continuous, user-toggled visualizer input, not occasional short recording, so the Microphone Button recommendation does not apply.

**Critic Verification**: Automatically verified (bypassed critic review). (Confidence: High)
- **Recommendation**: Check that the mic stops when the app is backgrounded, for example by calling setMicEnabled(false) or pausing MicCapture on ProcessLifecycleOwner ON_STOP and resuming on ON_START when the preference is on. This keeps an AudioRecord thread from staying open while the app is minimized and makes the behavior clear to Play reviewers. Do not add a microphone foreground service type unless background mic capture becomes an intended, disclosed feature.
- **References**:
  - https://support.google.com/googleplay/android-developer/answer/10144311
  - https://support.google.com/googleplay/android-developer/answer/16558241
